# Tether — Visual Identity & Brand Assets

## Overview
Tether maintains a consistent, high-fidelity visual identity across all platforms, binaries, installers, web surfaces, and documentation. The brand mark depicts the local wireless bridge between an Android phone and a Windows workstation, united by a high-intensity cyan/blue glowing tether.
